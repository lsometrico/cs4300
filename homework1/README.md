# CS4300 - Homework 1 - Python scripting 
This repository contains a collection of python scripts as part of CS4300 Assignment 1, with different tasks as well as accompanying tests utilizing pytest. It covers the basics, functions, control structures, etc. 

## Setup 
On the command terminal run the following: 
```
pip install -r requirements.txt
```
## Running the tests 
To run the collection of tests, run from the homework1 directory with the following command:
```
python -m pytest 
```
## Files

| File | Description |
|---|---|
| `task1.py` | Prints "Hello, World!" |
| `task2.py` | Demonstrates int, float, string, and boolean data types |
| `task3.py` | If/elif/else check, for loop over primes, while loop summing 1–100 |
| `task4.py` | `calculate_discount` — duck-typed function, works with int or float |
| `task5.py` | A list of favorite books and a student ID dictionary |
| `task6.py` | Reads `task6_read_me.txt` and counts its words |
| `task7.py` | Uses NumPy for basic array stats and a dot product |
